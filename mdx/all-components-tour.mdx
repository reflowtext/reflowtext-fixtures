## Install the companion CLI

<Tabs>
<TabItem value="npm" label="npm">

```bash
npm install --global @halcyon-example/patch-cli
halcyon login --device aurora-02
```

</TabItem>
<TabItem value="pnpm" label="pnpm">

```bash
pnpm add --global @halcyon-example/patch-cli
halcyon login --device aurora-02
```

</TabItem>
</Tabs>

<Accordion title="Why patches are signed on the instrument">
A patch is signed by the synthesizer that created it, so a shared patch can never be altered on its way to another player. The cloud stores the signature with the patch and checks it again on every download.
</Accordion>

<Steps>
<Step title="Connect">Plug the instrument in over USB-C and run `halcyon login`.</Step>
<Step title="Back up">Run `halcyon backup` to upload every bank, signed.</Step>
<Step title="Share">Publish a bank with `halcyon share bank-04 --public`.</Step>
</Steps>
